## 桌面验收步骤（留作后续参考）

以下步骤不属于本次框架交付验收，未在发布 EXE 中执行。

1. 打开上面的发布 EXE。确认窗口标题为「工创 · 小车地面站」，默认窗口能显示地图、任务面板和「模拟驾驶」，不用连接 Pi。
2. 点击「启动任务」，确认模拟车位姿开始变化；点击「模拟急停」，确认显示「模拟急停已锁定」、位姿停止变化。截图留存。
3. 点击「解除急停」，确认位姿保持不变；再点击「继续任务」，确认位姿恢复变化。
4. 把窗口缩至约 480 像素宽，切到「地图」，确认地图仍可见、顶部状态及急停按钮未被截断或相互覆盖；切到「任务」确认仍能解除急停。记录正常与急停截图，若有问题记录窗口尺寸和实际表现。

## 复现构建

从 x64 Native Tools Command Prompt 运行 [build-windows.cmd](../build-windows.cmd)。本机也可运行 [build-local-x64.cmd](../build-local-x64.cmd) 初始化实际安装位置的 x64 工具环境。默认离线，需要已缓存的锁定依赖。

## 历史阻塞

此前微软安装引导包报 0x80096004。本机诊断表明同一官方 OPC 包的内容签名通过，证书链缺 Microsoft Windows Code Signing PCA 2024。补齐中间证书后用户进入组件选择页并完成工具链安装。
