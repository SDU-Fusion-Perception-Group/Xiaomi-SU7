# 智能搬运初赛 · 首屏美术交付约定
首件交付是可在地面站里查看的地图合成效果，而不是单个按钮的改色截图。

1. **生图交付**：用 reverix-image 生成方形正交俯视工业场地底画，先出一张 1024×1024 PNG。画面语言是深石墨色哑光地坪、冷蓝灰细微材质、均匀顶光；保持路线、标签和车体的识别优先级。不要生成文字、UI 按钮、路径、台阶或假障碍。最终作为地图静态背景，可随场地变换同步缩放，不作屏幕壁纸。
2. **赛规配准**：用图 1 的 2400 mm 正方形四角对齐底画；两个蓝色启停区、四块禁入区、400 mm 中央车道、加工/暂存/原料装置保留可核验的矢量尺寸。地点标签、模拟/实测来源、车头朝向与点云独立绘制。模拟路线默认隐藏。
3. **控件自行实现**：顶部参考 DJI/QGC 的窄状态栏，右下角图层和比例工具、左下航向仪；Vue 组件 + Lucide 线图标。急停即停，解锁不启动，不用确认弹窗拖慢急停。正常色不发光，红色只用于危险。无真实电量或信号时不造数。
4. **验收**：实际合成截图和原图一起看；按缩放检验贴图不漂移、禁入边界不偏移，检查小车和告警辨识度。没有生成 PNG 时明确写“尚未出图”，不用手绘冒充生成素材。
