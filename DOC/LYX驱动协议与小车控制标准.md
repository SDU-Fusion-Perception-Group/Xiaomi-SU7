# LYX 步进驱动协议与小车控制标准

本文是后续协议开发的标准依据，适用于当前实测的 LYX9233 成品驱动板，芯片型号回读值为 `2336`。资料来源为 `DOC/LYX步进电机驱动芯片规格书V6.0.pdf` 和本轮实际通信测试。规格书中的示例 CRC 存在错误，本文所有示例帧均已按 Modbus CRC-16 重新计算。

## 1. 当前硬件约定

| 项目 | 标准值 |
| --- | --- |
| 物理接口 | RS485，A 对 A，B 对 B，信号地非必须 |
| 协议 | Modbus RTU |
| 串口格式 | 8 数据位、无校验、1 停止位 |
| 当前波特率 | 115200 bps，全部电机已设置并保存 |
| 当前从站地址 | 1，多电机使用前再分配唯一地址 |
| 电机 | 两相 1.8°，200 整步/圈 |
| 运动脉冲基准 | 256 脉冲 = 1 整步，51200 脉冲 = 电机轴 1 圈 |
| 使能脚 | 当前 ENA 悬空，内部上拉为高电平 |
| 当前使能配置 | `0x18 = 1`，高电平有效 |
| 当前闭环模式 | 超级闭环，`0x21 = 2` |
| 当前报警 | `0x08 = 0`，线圈已检测到 |

DM-MC02 后续接入时使用 USART3：PD8 为 TX，PD9 为 RX，PB14 为 DE。驱动板与固件 `BOARD_RS485_BAUDRATE` 当前统一为 115200。

电源不能处于限流保护状态。限流会导致上电线圈检测失败，`0x08` 变为 2，同时 `0x04` 至 `0x07` 全为 0。

## 2. Modbus RTU 帧格式

CRC 使用多项式 `0xA001`，初始值 `0xFFFF`，结果低字节在前。

| 功能码 | 用途 | 主机帧 | 正常从机应答 |
| --- | --- | --- | --- |
| `0x03` | 读保持寄存器 | 地址、功能码、起始地址、数量、CRC | 地址、`0x03`、字节数、数据、CRC |
| `0x06` | 写单个寄存器 | 地址、`0x06`、寄存器、值、CRC | 正常时回显主机帧 |
| `0x10` | 写多个寄存器 | 地址、`0x10`、起始地址、数量、字节数、数据、CRC | 地址、`0x10`、起始地址、数量、CRC |

单次最多读写 16 个寄存器。异常应答的功能码为原功能码加 `0x80`，第三字节是异常码。当前实测的 `01 86 04 43 A3` 和 `01 90 04 4D C3` 都是异常码 `0x04`，表示从机处于故障状态并拒绝执行。

地址 0 是广播地址。广播只允许使用 `0x06`，从机不回包，因此只有在通信稳定后才能用于多电机同步启动。

## 3. 上电检查

先读取报警：

```text
01 03 00 08 00 01 05 C8
```

正常返回：

```text
01 03 02 00 00 B8 44
```

报警值含义：

| 值 | 含义 | 处理 |
| --- | --- | --- |
| 0 | 无报警 | 可以配置和运动 |
| 1 | 过流 | 检查电源、电流和采样电阻 |
| 2 | 电机未连接 | 检查线圈跨接、电源限流和使能 |
| 3 | 线圈异常 | 两相电阻或电感相差超过约 2 倍 |
| 4 | 闭环超差 | 超差保护停机，需重新使能 |
| 5 | 堵转或编码器校正失败 | 规格书正文定义为堵转；校正章节也用 5 表示校正失败，需结合 `0x23`、`0x29` 判断 |

再读取 A/B 相参数：

```text
01 03 00 04 00 04 05 C8
```

返回数据顺序是 B 相电阻、A 相电阻、B 相电感、A 相电感。正常时应全部非零且两相接近。当前实测值：

| 参数 | 实测值 |
| --- | --- |
| B 相电阻 | 1009 |
| A 相电阻 | 960 |
| B 相电感 | 2219 |
| A 相电感 | 2111 |

一组线圈必须接在 A+ 与 A- 之间，另一组接在 B+ 与 B- 之间。同一相接反只会反向；把一组线圈拆到两个不同相会形成断路并报报警值 2。

## 4. 通信参数

| 寄存器 | 名称 | 范围 | 当前/默认 | 说明 |
| --- | --- | --- | --- | --- |
| `0x00` | 保存参数 | 写 1 | 无 | 保存所有“读写存”参数，运动参数不要求保存 |
| `0x01` | 波特率 | 96、192、384、768、1152、2304、4608 | 1152 | 当前全部电机为 115200，重新上电后生效 |
| `0x02` | 从站地址 | 1–256 | 1 | 当前默认地址 1，多电机时再改为唯一地址 |
| `0x03` | 芯片型号 | 只读 | 2336 | 前三位是型号，末位是固件版本 |
| `0x11` | MS 引脚作用 | 0–1 | 0 | 0 设置细分，1 设置通信地址 |

设置 115200 并保存：

```text
01 06 00 01 04 80 DB 6A
01 06 00 00 00 01 48 0A
```

保存后必须断电重启，并把主机波特率改成新值。

## 5. 使能标准

| 寄存器 | 值 | 含义 |
| --- | --- | --- |
| `0x18` | 0 | ENA 低电平使能，高电平关闭 |
| `0x18` | 1 | ENA 高电平使能，低电平关闭；当前全部电机已设置 |

ENA 悬空时由于内部上拉而处于高电平。当前配置已经匹配，确认帧为：

```text
01 06 00 18 00 01 C8 0D
```

这样悬空即使能。若希望外部低电平使能，则写 `0x18 = 0`，并确保控制脚确实输出低电平。

报警 1、2、3、4、5 触发后，需要一次从“关闭电平”到“使能电平”的跳变才能重新检测和退出保护。仅保持原电平不会解除报警。

## 6. 角度、速度和位置单位

| 单位 | 换算 |
| --- | --- |
| 电机轴角度 | 51200 脉冲 = 360°，1 脉冲 = 0.00703125° |
| 整步 | 256 脉冲 = 1.8° |
| 位置寄存器 | `0x0C:0x0D` 组成 32 位有符号位置 |
| 速度寄存器 | `0x0E` 为 16 位有符号数，256 = 1 rpm |
| 误差角度 | `0x10` 为 16 位有符号数，256 = 1 整步 |
| 运动速度 | `0x3A`、`0x3B` 直接使用 rpm |
| 加速度 | `0x3C` 使用 rpm/s，最小 60 |

位置模式的脉冲数是相对运动量，不是目标绝对坐标。正方向由 `0x3F` 决定。

## 7. 运动控制

寄存器顺序必须是：

1. `0x3A` 启动转速，0–1200 rpm。
2. `0x3B` 最高转速，1–15000 rpm，且不小于启动转速。
3. `0x3C` 加速度，60–60000 rpm/s。
4. `0x3D:0x3E` 脉冲数；速度模式可不写。
5. `0x3F` 运动模式。
6. 最后写 `0x40 = 1` 启动。

运动模式：

| `0x3F` | 模式 |
| --- | --- |
| 0 | 位置正转 |
| 1 | 位置反转 |
| 2 | 速度正转 |
| 3 | 速度反转 |
| 4 | 正转堵转回零 |
| 5 | 反转堵转回零 |

`0x40 = 1` 启动，运动结束自动变回 0；写 0 可立即停止。位置运动期间轮询 `0x40`，返回 1 表示尚未完成，返回 0 表示完成。

### 7.1 速度模式

以下命令使电机以启动 30 rpm、最高 60 rpm、加速度 60 rpm/s 连续正转：

```text
01 06 00 3A 00 1E 29 CF
01 06 00 3B 00 3C F8 16
01 06 00 3C 00 3C 49 D7
01 06 00 3F 00 02 38 07
01 06 00 40 00 01 49 DE
```

停止：

```text
01 06 00 40 00 00 88 1E
```

### 7.2 位置模式

以下命令相对正转一圈：

```text
01 06 00 3A 00 1E 29 CF
01 06 00 3B 00 3C F8 16
01 06 00 3C 00 3C 49 D7
01 10 00 3D 00 02 04 00 00 C8 00 76 8A
01 06 00 3F 00 00 B9 C6
01 06 00 40 00 01 49 DE
```

反转一圈只把 `0x3F` 改为 1：

```text
01 06 00 3F 00 01 78 06
```

十圈是 `51200 × 10 = 512000` 脉冲，脉冲寄存器写 `0x0007D000`。

## 8. 闭环与运行模式

`0x21` 只有在 MOD 引脚为低电平时生效。MOD 为高电平会强制开环。

| `0x21` | LYX9233 模式 |
| --- | --- |
| 0 | 开环 |
| 1 | 普通有感闭环 |
| 2 | 超级有感闭环 |
| 3 | 伺服闭环 |
| 4 | 力矩电流模式 |

当前成品板回读为超级闭环。小车轮轴控制默认使用超级闭环；需要更严格的位置跟踪时再整定伺服闭环。

闭环相关寄存器：

| 寄存器 | 名称 | 当前实测值 | 作用 |
| --- | --- | --- | --- |
| `0x22` | 堵转阈值角度 | 240 | 256 = 1 整步；堵转默认不停机 |
| `0x23` | 堵转输出使能 | 1 | 1 时堵转拉低 ALM |
| `0x24` | 超差阈值角度 | 1024 | 超差会停机 |
| `0x25` | 超差停机使能 | 0 | 当前关闭超差停机 |
| `0x26` | 积分分离转速 | 0 | 256 = 1 rpm |
| `0x27` | 基础电流 | 128 | 当前等于最大运行电流 |
| `0x28` | 超前系数 | 32 | 越大相位越超前 |
| `0x2B` | 位置环积分 | 8 | 提高低速定位精度 |
| `0x2C` | 超级闭环滤波 | 16 | 越大越稳但延时越大 |
| `0x2F` | 伺服位置积分 | 1 | 仅伺服模式 |
| `0x30` | 伺服位置比例 | 64 | 仅伺服模式 |
| `0x31` | 伺服位置微分 | 5 | 仅伺服模式 |
| `0x32` | 伺服速度前馈 | 15 | 仅伺服模式 |

当前运行电流 `0x13 = 1300`。电流参数与板载采样电阻相关，未完成整车负载测试前不要随意提高。

## 9. 小车控制标准

本文件只定义驱动协议，不包含比赛任务流程。轮子控制应把车体速度转换为每个电机轴的相对脉冲或目标 rpm。

推荐周期：

1. 上电后读 `0x08`，确认报警为 0。
2. 读 `0x18`，确认当前硬件电平与使能极性一致。
3. 读 `0x21`，确认 MOD 为低且模式为预期闭环模式。
4. 以 20 Hz 轮询 `0x08`、`0x0C:0x0D`、`0x0E`、`0x10`、`0x40`。
5. 每次运动先写 `0x3A` 至 `0x3F`，最后写 `0x40`。
6. 新命令发出前，先确认上一次位置运动已经结束，或先写 `0x40 = 0`。
7. 报警非 0 时禁止发新的运动命令，执行重新使能流程后再检查 `0x08`。

车体换算由上层保留：

```text
电机轴 rpm = 车轮目标线速度 / 车轮周长 × 60 × 减速比
相对脉冲 = 目标轴角度 / 360 × 51200
```

减速比、车轮直径和轮距尚未在驱动协议中固定，必须由小车机械参数单独定义。驱动层不得假设这些值。

多轮同步时，每个驱动板使用不同的 `0x02` 地址。各轮参数分别写完后，才允许用广播地址 0 写 `0x40 = 1` 同步启动。

## 10. 固件寄存器对照

`firmware/module-bench/Protocol/lyx_motor.h` 的模式枚举与本文一致。当前实现使用：

| 固件符号 | 寄存器 | 标准含义 |
| --- | --- | --- |
| `LYX_REG_SAVE` | `0x00` | 写 1 保存配置 |
| `LYX_REG_ALARM` | `0x08` | 报警值 |
| `LYX_REG_ERROR_ANGLE` | `0x10` | 16 位有符号误差角度 |
| `LYX_REG_CONTROL_MODE` | `0x21` | 仅 MOD 低电平时生效 |
| `LYX_REG_START_RPM` | `0x3A` | 启动 rpm |
| `LYX_REG_MAX_RPM` | `0x3B` | 最高 rpm |
| `LYX_REG_ACCELERATION` | `0x3C` | rpm/s，最小 60 |
| `LYX_REG_PULSE_HIGH` | `0x3D:0x3E` | 相对运动脉冲 |
| `LYX_REG_MOTION_MODE` | `0x3F` | 位置、速度或堵转回零 |
| `LYX_REG_MOTION_START` | `0x40` | 1 启动，0 停止或已完成 |

实现时还必须读取 `0x0C:0x0D` 的 32 位轴位置和 `0x0E` 的有符号转速。速度换算为 `rpm = 原始值 / 256`，轴角度换算为 `度 = 脉冲 × 360 / 51200`。

## 11. 外置 Flash 存储

协议层存放在板载 W25Q64 的起始扇区，容量按 8 MB（`0x800000`）编址。官方驱动是 `CtrBoard-H7_ALL/Bsp/w25q64.c`，使用 OCTOSPI2，JEDEC ID 为 `0xEF4017`。

| 项目 | 值 |
| --- | --- |
| 映射地址 | `0x90000000`，对应 W25Q64 偏移 0 |
| 占用大小 | 一个 4 KB 扇区 |
| 魔数 | `LYXP`，小端数值 `0x4C595850` |
| 版本 | 2 |
| 当前内容 | 115200、地址 1、高电平使能、超级闭环、51200 脉冲/圈 |

W25Q64 在启动时切换到 OCTOSPI 内存映射模式，CPU 可直接读取 `0x90000000` 至 `0x907FFFFF` 的 8 MB 空间。正常运行不擦除、不写入。协议记录位于映射区起始处；后续地图、参数和日志按同一地址空间追加。记录损坏时启动失败，需用维护工具重写外部 Flash。

## 12. 小车运动接口

当前机械标定宏位于 `firmware/module-bench/Bsp/board_config.h`：

| 宏 | 当前值 | 含义 |
| --- | --- | --- |
| `BOARD_WHEEL_DIAMETER_MM` | 75 | 轮子直径，单位 mm，后续更换轮径只改此值 |
| `BOARD_WHEEL_TRACK_MM` | 200 | 左右轮距，单位 mm，实测后修改 |
| `BOARD_WHEEL_PULSES_PER_REV` | 51200 | 电机轴一圈脉冲数 |

换算公式：

```text
轮周长 = π × 轮径
前进脉冲 = 距离 / 轮周长 × 51200
原地旋转弧长 = 轮距 × π × 角度 / 360
旋转脉冲 = 旋转弧长 / 轮周长 × 51200
```

USB 文本命令以回车结束：

| 命令 | 动作 |
| --- | --- |
| `drive 10` | 前进 10 cm |
| `drive -10` | 后退 10 cm |
| `cw 90` | 顺时针旋转 90° |
| `ccw 90` | 逆时针旋转 90° |
| `fw [rpm]` / `rv [rpm]` | 单轮持续正转或反转 |
| `stop` | 停止 |

当前固件只连接了一台地址为 1 的电机，左右轮接口暂时指向同一电机，用于验证换算和命令。接入第二台电机并分配唯一地址后，同一接口分别控制左右轮。

## 13. 实测状态摘要

| 项目 | 结果 |
| --- | --- |
| 115200、地址 1、使能有效信号 1 | 当前全部电机配置 |
| 线圈参数 | 全部非零且两相接近 |
| 报警 | 0 |
| ENA 悬空 | 必须使 `0x18 = 1` 才使能 |
| 参数写入 | 报警期间返回异常码 `0x04` |
| 报警清除后 | 参数写入得到正常回显 |

因此协议实现必须检查每一帧的功能码和 CRC，不能只判断“收到了回包”。功能码带 `0x80` 即表示命令未生效。
